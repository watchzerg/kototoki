# ADR-0002：X0 复用入口与无VAD流程适配

状态：无VAD／fixed30基线选择已被[ADR-0003](0003-new-pyannote-baselines.md)替代；Qwen兼容适配、原生特征及复用入口原则继续有效  
日期：2026-10-05  
范围：X0 demo的组织方式和支持的流程策略，不改变模型／依赖选择。

## 背景

此前[小样本研究](../research/2026-10-05-x0-whisperx-flow.md)把低能量切点与VAD过滤列为实验，
采用了“两片无观测回归才扩展”的规则。用户随后明确：目标是吸收WhisperX合理的流程逻辑，
不是移植VAD，也不要求有限样本证明显著优势后才能采用合理设计；并要求建立与W0对应的固定X0 demo。
旧实验数据和结论保留其范围，不再作为建立可复用流程能力的门槛。

## 原决定（新Pyannote采纳前）

用户再次确认：X0保持无VAD、固定30秒，只吸收逻辑合理且适用于Qwen的WhisperX流程。
独立纯文字解码和原生特征已有等价行为；不要求照搬Whisper的特征或基于VAD的切分合并。
下述低能量cut-merge是实现中额外提供的实验，不是用户指定基线的必要组成，也不是完整移植的证明。

- 当前X0持续迭代入口为 `experiments/x0_demo/`。保留[ADR-0001](0001-two-stt-baselines.md)的默认固定30秒、无VAD＋Qwen＋MMS基准。
- 提供有独立身份的 `cut-merge` 策略：用轻量音频能量产生候选切点，按原音频跨度合并到有界窗口，保留全部样本。这是方法适配，不声称与WhisperX神经VAD后处理逐项等价。
- 候选切点、合并、独立Qwen识别和MMS接口分开。Qwen已有独立纯文字解码，将其明确为契约；特征仍交给本机Qwen processor。
- MMS复用W0现有实现，增加可选整数样本窗契约；原W0秒坐标路径保持原行为。ASR和MMS消费同一音频片段，不创建第二套对齐器。
- 入口自动连接既有两个推理环境，保存新运行身份、完整文字、失败和源坐标。历史实验留作回归参照，正式后端迁移另行验收。

## 理由与取舍

固定30秒是可复现的参照。候选边界与有界合并让音频切分不必完全忽略声音结构，同时避免过多短窗；
保持全部音频减少由检测漏检直接丢对白的风险。低能量不等于语音结束，因而不宣称准确率必然更高。
采用的是职责边界和合理的处理方法，质量结论仍需单独评价。

不采用Pyannote或其他VAD作为X0必要组件；不迁入Whisper token、固定Mel、CT2解码或原生字幕句切。
完整引入WhisperX会增加不适用的依赖和语义；复制整套流水线也会让W0／X0的MMS维护分叉。

## 验证与后果

[demo契约](../specs/x0-reusable-demo.md)定义样本守恒、30秒边界、完整文字、实际GPU及错误记账等验收项。
实测用于验证实现和揭示回归，不以每个小样本指标都更好作为允许存在该策略的条件。
对特定质量或性能提升的宣称仍须有可复现证据，不能用设计直觉代替测量。

后续X0改动复用本demo，分段／模型／解码变化更新recipe和验证记录；不改写历史研究的旧成绩。
