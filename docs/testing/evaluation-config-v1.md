# 第一轮筛选规则

状态：决策规则与六个晋级配置已确定；源码身份清单冻结后开始验证  
日期：2026-10-04  
范围：FateStay 固定开发、验证和保留范围的探索性工程选型；不构成产品验收标准。

## 身份与不可变项

本规则绑定历史单片冻结，不因当前语料优先级更新而改写。后续 II、III 主参考及 I/Black Panther 补充评估遵循[当前素材规范](fatestay-reference.md)，直接读取已分离音频，并另冻输入、分集与规则适用范围；本轮分母、阈值和既有成绩不自动成为新轮次的验证结果。

使用[语料冻结](2026-10-04-corpus-freeze.md)的章节划分、源时间与 PCM，
`.local/references/scoring-v2/` 参考（只排除明确非口述的四条制作信息），
`nfkc-punctuation-v2-universal-complete-invariant-boundaries` 计分规则。
开发 N=195、验证 N=151、保留 N=620；整片 N=1026，包含章节缓冲区。
晋级前保存候选配置、参考、评测源码和输入文件 SHA256 清单。从首次验证结果产生起不改变排除项、
文字规范化、失败记账、阈值、排序或 writer 规则；必要修复另开已接触测试集的轮次。

## 资格与保护条件

严格时间目标仍为 E=max(|ds|,|de|)，P95<0.5 秒、P99<2 秒。
为避免只对少数成功项宣布达标，保守的完整性与时间联合观察要求
`success_lower_count(0.5) >= ceil(0.95*N)` 且
`success_lower_count(2) >= ceil(0.99*N)`；明确失败保留分母，未决不算确定成功。
条件分位数、完整覆盖率、失败类型及上下界必须同时报告。
有参考不确定区间时，确定成功须以区间内最大可能 E 判定；这不等同仅使用点估计的联合分位数。

相对 SRT 的观察资格与声学资格分开。没有独立人工声学文字、边界和不确定区间时，
声学资格始终为未验证。独立文字质量与最终显示体验尚无足够依据设定绝对验收线，
因此即便某项时间观察达到目标，也不能宣布产品整体合格。单片结果不能提供一般 P99 保证。

暂定工程路径必须证明本机原生 Windows、实际 GPU ASR/FA、离线重载和全部固定范围记账。
新增推理模型也须有实际 GPU 证据。Crisp 原生 Silero VAD 的 CPU 执行作为明确披露的
原生预处理例外保留，不能宣称全流水线 GPU；ASR/FA 不允许 CPU 回退。
设备未知、输入身份未知、只完成部分开发范围的配置不能作为完整工程路径晋级。
结构错误或无效时间保留为失败，不能通过删除文字或填造时间消除。
达到生成 token 上限而非正常终止须列为截断/生成失败，保留已有文字参与描述性计分；
该配置在开发范围内仍有未解决的生成失败时，不晋级为稳定工程路径。

## 开发晋级与验证选择

每条路线最多 12 个开发配置，W1/W1-native 共用预算；有依据的跨家族分支最多另加四个。
局部诊断不是新的独立样本。无收益方向停止，不为用满预算运行。

先比较完整五章的 CER、D、I、精确字符覆盖、首尾完整覆盖、可测覆盖、
全 N success(0.5/2/5) 上下界、失败及条件尾部。文字使用完整字符分母，联合率使用固定跨度 N，
条件尾部附可测 n；失败/不支持范围不能删去。
默认自动替换须无观测回归：CER、D、I 不增加，完整/可测覆盖及成功率下界不降低，至少一项改善。
无观测回归不等于用户容忍度为零；非支配配置可作为明确取舍继续研究，但不能据此宣称退化可接受。
没有证据支持绝对 CER/删除率容忍度，故本轮不臆定数值保护线。

Pareto 轴固定为 CER、D/Nchar、I/Nchar（越低越好），首尾完整覆盖、可测覆盖及
success_lower(0.5/2/5)（越高越好）。不同有效子集的条件尾部用于诊断，不作为额外支配轴；
成本仅用于下述破同，缺测不能视为零。每路线 Pareto 集中最多两个角色进入验证：

- 时间角色：全 N success_lower(0.5) 降序、success_lower(2) 降序、D/Nchar 升序、CER 升序。
- 内容保全角色：D/Nchar 升序、CER 升序、I/Nchar 升序、success_lower(0.5) 降序。

各取第一个；同一配置兼得则只进入一个。完全相同先参考独立重复测得的成本，未测则选组件较少者，
最后用固定 configuration_id 字典序缩减预算；这些破同不代表质量有统计差异。
W0 作为识别/工程对照，验证后按内容保全角色锁定一个；W1、Q0、Q1 及 X0 跨家族组合为字幕时间研究，
验证后按时间角色锁定一个。保留测试之前公布锁定清单，之后不能换配置仍称同轮盲测。
如果排序赢家新增删除、插入或其他质量退化，必须在结论中显式列出取舍；排序不能使其自动通过质量资格。

未决上下界可翻转排序时不宣布确定胜出；可继续透明的工程选择。
只在共同有效子集辅助解释时间差异，同时保留各自全分母结果。
场景不足十个不生成成组 bootstrap 区间；足够时 2000 次、seed=20261004，保留场景内相关性。

## 保留、整片和重复性

每路线仅一个冻结配置进入保留集。保留比较完成后，最多两个有明确独立价值的配置各做一次整片运行；
整片是不同上下文条件，不能用章节结果替代，也不能当作新增独立测试集。
若多数配置均有弱质量，只称最佳已测或诊断路径，不为凑数量推荐。

入围者在同一固定片段进行三次无推理缓存运行，记录输出变化、冷启动、各阶段时间、总体 RTF、
显存和设备；GPU 串行，最终测速不并行下载/评测。保存 ASR 的 FA 重算只计实际重算阶段成本。
重复不增加 N，不平均时间戳掩盖偶发失败。数字静音单列插入/事件计数，N=0 的 CER 未定义，
不能用它证明音乐场景稳健性。

所有严格资格、工程选择、显示体验和统计限制均分别报告。参见
[评估标准](subtitle-timing-benchmark.md)、[实验汇总契约](demo-analysis-contract.md)和
[执行记录](../context/2026-10-04-demo-execution.md)。
