## 结论

- **工程行为全部通过**：无语音视频、5.1 声道下混、损坏文件隔离、子目录镜像、asr 阶段中途强杀（Job Object 让 worker 随之退出、显存释放）、残留锁默认拒绝与 `KOTOTOKI_BREAK_STALE_LOCK=1` 续跑、用户改动最终文件时不覆盖与 `force = true` 覆盖、重跑结果逐字节一致。
- **质量回归未达基线**：同一评分器下，产品 STT 的 CER 高于 2026-10-05 基线（w0：II 20.29% 对 16.81%，III 14.24% 对 13.77%；x0：II 20.55% 对 18.30%，III 15.94% 对 15.14%），差距几乎全是删除。根因已核实：派生 WAV 改用 soxr（规格 §1.2，2026-10-14 裁定）后 Pyannote 少保留约 9–10% 的语音；产品 VAD 在基线的 swr 版 WAV 上得到与基线完全相同的窗口。
- **一个产品缺陷**：`media._tag_duration` 把 mkvmerge 的统计标签 `DURATION-<lang>` 与 `DURATION` 等同，流复制剪辑保留旧 `DURATION-eng` 时整个文件被误判为"音频短于视频"而失败。
- **一个 cue 观感问题**：按字符时间间隙切分会把一个词切到两条 cue（样本中"先輩"被切成"先"／"輩"）。

## 3. 真实环境的失败路径（GPU）

输入 `accept/input/`：HF III 20–25 分钟片段（重编码 320×240，FLAC 立体声）、`sub/silent-30s.mp4`（合成无声）、`sub/clip-51-1min.mkv`（60 s，ac3 5.1(side)）、`broken.mkv`（文本文件）。配置只写路径与 `stable_check_s = 2`。

| 项 | 做法 | 结果 |
| --- | --- | --- |
| 无语音 | `silent-30s.mp4` | vad 0 窗口 → 跳过 asr／align／翻译，发布三份零条目 SRT，日志 `(no speech)`；第二次运行判定 up to date |
| 5.1 下混 | `clip-51-1min.mkv` | 选中 jpn ac3 5.1(side)，`pan=mono|c0=0.242659*c0+0.242659*c1+0.171560*c2+0.171560*c4+0.171560*c5`（LFE 不入），时长校验通过，4 条 cue 发布 |
| 损坏文件 | `broken.mkv` | ffprobe 失败 → extract 阶段 `MediaError`，`failure.json` 写明原因，其余文件照常，退出码 1 |
| 子目录镜像 | `sub/` | 输出 `out-b/sub/*.srt`，工作目录按短 id |
| 流复制剪辑 | 第一次用 `-c copy` 剪的片段 | **失败**：报"解码音频比视频流短 7022 s（303 对 7325）"；根因见下 |
| 中途强杀 | `[asr] start` 后 4 s 对编排器真实进程 `Stop-Process -Force` | 编排器、worker 启动器与真实 worker（2.7 GB 工作集）5 s 内全部退出，显存回到桌面基线；`.local/gpu.lock` 与 `.work/lock` 残留 |
| 残留锁 | 直接重跑 | 退出码 3，消息指明死 pid 与 `KOTOTOKI_BREAK_STALE_LOCK=1` |
| 续跑 | 带环境变量重跑 | 两把锁被移除，vad 产物按身份跳过，从 asr 继续，67 s 完成；gpu.lock 运行后释放 |
| 确定性 | 对比 out-b 与 out-c 的 `ja.srt`／`zh.srt` | 三份文件 SHA256 完全相同 |
| 用户改动 | 向 `clip-5min.zh.srt` 追加一条后重跑 | 扫描阶段告警 `changed by user (zh), skipped`，计入 blocked，不进 GPU，文件未动 |
| `force = true` | 同上再跑 | 翻译按批次记录复用（0.0 s），重新发布，`published.json.previous_sha256` 记录被覆盖的三份 SHA，`zh.srt` 恢复为原 SHA |

**缺陷：`DURATION-<lang>` 统计标签**。`media._tag_duration` 遍历 `tags`，`DURATION` 与 `DURATION-<lang>` 同等接受、先到先得。ffmpeg `-c copy` 剪出的 mkv 会保留原片 mkvmerge 写的 `DURATION-eng`（原片全长），自己再写正确的 `DURATION`；ffprobe 返回时 `DURATION-eng` 在前，产品取到原片时长，把合法文件判为截断。影响范围：任何从 mkvmerge 产出的文件再经 ffmpeg 流复制剪辑的输入。建议：先取精确的 `DURATION`，没有时再取 `DURATION-<lang>`，并在二者与 `format.duration` 相差超过阈值时告警而非失败。
