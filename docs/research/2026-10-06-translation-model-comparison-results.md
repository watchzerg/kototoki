# 五个本地日译中字幕候选的固定 test 比较

日期：2026-10-06。状态：**计划执行完成；质量比较为暂定，语义覆盖不完整**。三个家族的 demo、五版本 smoke/dev、配置冻结和全部固定 test 任务已执行；415 个候选窗口中 408 个有语义终分，6 个映射不可评、1 个裁决未决。没有以人工日语复核补齐缺分。

本机条件下，**Hy-MT2 30B-A3B Q3_K_M 是优先继续试用的质量／速度候选，Hy-MT2 7B Q8_0 是显存余量更大的选择**。前者两类语义均值较高且生成最快，但需独立兼容 loader，整卡采样峰值为 15,271 MiB（约 14.91 GiB），余量有限。电影上两者差距仅 0.125 分，不能据此宣称跨作品稳定胜出。

## 配方、隔离与结论限制

本轮比较 `V2-native-adapted` 固定窗口流程，评价采用 `sol-high-auto-v1`。三个家族、五个指定版本均已在原生 Windows／RTX 5080 上完成原生 smoke/dev 和完整 test。test 为 83 个窗口、414 个计分 IDs，五候选共 415 个预期候选窗口；电影 4 个作品／20 窗口，剧集 11 个作品／63 窗口。smoke 是 dev 子集，开发分数不混入 test。

每个作品先取窗口语义均值，再在电影、剧集内分别按作品等权。语义为 0–4，自然度为 0–2，二者不相加。缺失语义终分按 0／4 分别代入全分母，得到缺分下界／上界；这不是置信区间。自然度仅汇总非空终分，并报告覆盖与省略作品。未决主评分不能缩窄缺分范围。

Hy-MT2 与 Tower+ 按源 ID 输出 JSON。TranslateGemma 先生成原生整窗段落，再使用本地 Tower+ 9B 做纯字符跨度映射；不改写中文、不读参考和裁判意见。连续计分组只保存一份中文并保留全部原 IDs，不伪造逐 cue 对齐。该 assisted 流程的成本与裸模型生成分开列出。TG12、TG27 分别有 2／4 个映射不可评；原生均 83/83 交付，映射 null 不记翻译零分。

冻结参数包括 temperature=0、seed=20261006、输出上限 1024 tokens、context=4096、每任务最多两次尝试、GPU offload=99、flash attention=on、fit=off、单槽、batch=256、ubatch=128；TG 原生输入上限 2048 tokens。五份实际 GGUF 原生模板逐字节对照通过。开发阶段发现字符串 /completion 被自动加入多余 BOS，已改成显式 /tokenize(add_special=false, parse_special=true) 后提交数值 token 数组；冻结前五版本真实运行及正式七阶段的输入／响应审计均通过。正式 test 后未依据内容调参。

引擎为 llama.cpp b11429（稳定 v0.6.0 对应提交 d81235049384534c167caea52b85a694f6103d14）、CUDA 13.4。Hy-MT2 30B-A3B 额外使用独立标识的 loader 兼容 DLL，处理发布 GGUF 中的偏置张量名称，不改权重；原 CUDA DLL 保持一致。五份权重正式推理后重新完整计算 SHA256，均匹配冻结清单。RTX 5080 记录为 16,303 MiB，驱动 616.92。

裁判每次只读取匿名的一个候选／一个窗口，显式请求 gpt-6.1-sol / high / fork_turns=none。主评全量执行；盲复评使用每作品固定 20% 抽样与跨五候选风险窗口并集，共 81 个窗口、399 个可评候选窗口。盲复评看不到主评结果，119 项分歧各安排一次新上下文裁决，格式／传输失败只允许一次重试。参考答案和裁判输出从未输入候选翻译或映射。没有人工日语复核。请求模型与设置可追溯，执行面未暴露的服务端实际版本、token 用量与费用保持未知。

计时区分每窗生成／辅助阶段时延、服务启动至 ready、整个本地运行墙钟和裁判调度时间。阶段时延包含 tokenize、HTTP 和全部重试，不是纯 GPU 核心时间；完整 runtime 已包含阶段，不能再相加。启动时间没有清空 OS 文件缓存，不能视为严格冷盘测量。显存是每秒采样的整卡峰值，包含其他进程，不是模型独占峰值。TG 两阶段串行，显存峰值取最大而非相加。失败开发版本、CLI 探针和中断保留，已记录成本单独列出，未记录成本保持未知。

两份主评 raw 在接受后再次写入：A/M04-2 仅摘要改变，B/10-3-3 仅一条错误理由及摘要改变；分数、IDs、类型、严重度、源／候选证据未改。已接受 canonical 及后续复评／裁决仍可追溯，但原先 raw 字节缺失，不能声称所有原始响应哈希完全闭合。逐字段审计保留原接受哈希、当前 raw 与 canonical 身份，不覆盖或追加语义重试。

结论限制：同模型参考文本复核与同模型自动裁判可能共享偏差，复评及裁决不能替代独立人工真值。少量作品、相邻窗口相关性、映射缺分和裁判不稳定限制排序；只报告条件化选择，不宣称统计显著优胜。模型大小与量化同时变化，不能把差异归因于单一因素。固定片段不代表整片泛化，未验收 SRT 显示布局或音画同步，也未接入 STT 产品功能。
