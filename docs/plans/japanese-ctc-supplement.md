## 固定范围

依据用户提供的[外部候选参考](../research/2026-10-04-japanese-ctc-alignment-reference.md)，
核验 Jonatas、Reazon rs35kh、MMS-1B Japanese adapter 与 slplab hiragana。
先核查原生 tokenizer、blank、许可和推荐预处理，再运行真实 GPU 推理。
模型获取与离线推理解耦，原音频及转写不上传；不升级旧环境或改写旧实验。

筛查固定为旧 round2 的 II／III window-01、window-04，共四窗 20 分钟。
复用已经验证身份的完整 ASR 文字、原 PCM 与源坐标：W0 使用已冻结的自身词时间包络，
W1／X0 使用原对齐搜索分段。不以参考 SRT 修改推理文字或搜索窗口。
参考仅进入计分阶段；旧窗口均已接触，不能称为盲测。

保留当前 Jonatas 及原 W0 无外部 CTC 的对照；新适配层先检查 Jonatas 与旧结果的时间一致性。
字符 CTC、子词 CTC、假名 CTC 分别遵循真实 token 语义。多字符 token 或假名词组只能提供
其整体时间，禁止按字符均分伪造精度。OOV／无法回映射的字符保留全文并记为无时间。
同模型的原生推荐预处理与固定管线消融如不同，使用独立配置身份。

## 评分与扩展

沿用[当前评分规则](../testing/evaluation-config-v1.md)与完整分母，报告参考字幕起止
均小于 0.5／2／5 秒的成功数、共同可测长尾、文字覆盖、CER／D／I、逐片结果和失败。
独立统计 tokenizer 覆盖、CTC 路径失败、GPU 型号与精度、加载／对齐时间、峰值显存。
缓存 ASR 成本不算作本次新端到端测速。

四窗中具备时间或覆盖收益、且接口可正确映射的配置可扩展到原十二窗 60 分钟。
扩展前另冻结配置，不据扩展成绩回调参数。没有收益的分支停止；有取舍的结果明确列出，
不把未全面支配旧配置解释为毫无价值，也不自动更换产品默认。
十二窗才计算固定 seed 的窗口成组 bootstrap；不新增独立声学标注或跨作品泛化主张。

四窗结果产生后锁定扩展：**X0＋Reazon 无物理填充**及 **W1＋Reazon 两侧 0.5 秒物理填充**，
分别另建十二窗计划。前者半秒成功 96/193，高于原 X0 的 90/193，且两片同向；
后者 96/193，高于无填充的 93/193 及原 W1 的 90/193，并保留长尾收益。
它们仍有中位偏移与逐片覆盖取舍，扩展用于补证，不是采用决定。
W0 的两种 Reazon 配置半秒成功均低于原 W0＋Jonatas，停止该分支扩展。
当时 MMS／hiragana 仍在独立四窗筛查，未因 Reazon 的结果提前判断其优劣。

MMS 加载顺序修复后的独立 v2 四窗全部成功。W1／X0 的半秒成功分别为 98／99（分母193），
两片均增加，可测覆盖也增加，因此同时冻结 **W1＋MMS、X0＋MMS** 的十二窗扩展。
这是与 Reazon 对称的补证，不因 MMS 较大或带 NC 许可而跳过质量比较；许可适用性单独报告。
W0＋MMS 的半秒成功为 81/193，低于原 W0＋Jonatas 的90，不扩展该组合。

假名初筛后另冻结 **W0＋hiragana** 十二窗：相对 W0＋Jonatas，半秒成功90→94，
两片各增加2条；共同可测113条的 P95 1.317→0.911秒。W1＋hiragana 虽半秒成功99条，
但 III 长尾恶化，暂保留低优先级取舍，不扩展；X0 无半秒收益且有一次读音回映射失败，停止扩展。
