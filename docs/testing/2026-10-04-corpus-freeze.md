## 派生参考与不确定性

参考格式为 `{schema_version:1,reference_kind:"srt_display",spans:[{id,text,start,end}]}`，另外保存原 cue、分集、原文和规则标记。初始保守规则只移除每行开头或整行的短括号 SDH 标签，内部括号及歌词文字保留并标记待复核。这份主字幕中实际没有匹配的括号标签或歌曲符号。没有发现符号不代表没有歌词、编辑文本或未发声文字。

后续仅查看源字幕，独立确认 cue 0001/0002/0003/0006 是中文字幕组制作声明、非商业用途声明及人员署名，属于明显非口述元数据。保留所有原始 v1 文件，新增 `fatestay-srt-scoring-v2-2026-10-04` 派生参考，明确记录这 4 个 ID 和理由；音频及章节分集不变。正式文字及时间分母因此为全片 1026、开发 195、验证 151、保留 620、隔离 60。全源结构检索只用于发现同类元数据；不会因“没有假名”便删除日语汉字台词。早期使用 v1 的分数被此源参考错误影响，应标记已失效并重算，不能用于选型结论。正式筛选前应用 v2；派生目录 `.local/references/scoring-v2/`，修订清单 `.local/manifests/corpus-reference-scoring-v2.json`。

40 个开发 cue 按等距序号预选，完成自动结构检查：时间区间为正、位于媒体范围、是否存在规则移除/空文本/未知标记。检查记录在 `.local/references/dev-text-audit.json`。这不能代替计划要求的人工听辨、文本正确性或声学边界抽查；这些验证仍待完成。没有生成或声称人工声学真值，也没有使用候选文本修订参考。

内部音频边缘在全范围共跨越 15 个字幕显示 cue。开发章 01/05/07 各 1 个，02/17 为 0 个；验证章 03/14/23 分别 2/1/2 个。完整可复核 ID 留在 `.local/manifests/corpus-reference-audit.json`。截断的边缘发声可能存在于输入却未包含于“完整位于内部”的文字参考，导致章节 CER 有边界归属不确定性。不能将这种差异自动归因于模型幻觉；全片连续文字统计保留所有参考项，是后续必要检查。字幕显示时间也不等于精确声学真值。

## 可复现实验入口与验证

### 独立数字静音预检

另外生成 `.local/audio/synthetic-silence-10s.wav`：16000 Hz、mono PCM16、160000 个全零样本，10 秒，源原点 0。它由 Python 标准库直接生成，不包含私人素材；PCM SHA256 `ac2878215ad33205d1732578c89f25ededaad1b676911c540825bcf4baa42d9b`，WAV SHA256 `ee7bea4232762775f8fce9b3e27e4d3948c8ac6a45a87ca769f703d6eed0b448`。`.local/manifests/corpus-synthetic-silence-10s.json` 冻结样本、哈希与来源；`.local/references/synthetic-silence-10s.json` 为 schema v1 空参考，明确 `synthetic_digital_silence` 类型。

此参考 `N=0`，单场景 CER 必须是未定义，不能记成 0；候选输出字符仍作为插入和数字静音输出记录，合并到含非零参考的整体评估时保留插入分子。没有时间匹配分母，不能报告 100% 时间覆盖或 success。当前评测器是否实现幻觉事件数量、事件合并及每分钟频率须另行注明；字符数不能代替这些尚未计算的指标。输出仅有标点时还须保留原始输出，不能因为文字规范化去除标点就宣称完全无输出。

aligner 没有输入文字是正常情况，跳过该步骤不能作为本条输入实际 FA GPU 执行证据。VAD 若完全过滤数字静音，也须记录是否实际调用 ASR；加载了 GPU 模型而没有执行音频推理不是本输入 GPU 运算的证据。静音预检速度不能代表正常语音速度。此样本不证明背景音乐、真实房间静音、弱语音或整片幻觉性能；chapter 02 的低字幕密度也不能证明它是静音。

生成命令为 `uv run --locked python experiments/corpus/prepare_silence.py`。生成/恢复及篡改后拒绝覆盖的 2 项合成测试已通过，无模型运行。评测器现已显式支持 synthetic_digital_silence 空参考类型，要求全零数字来源与空文字范围，不能伪装为人工或 SRT 真值；后续模型实测见执行记录。

### FateStay 操作

在仓库根目录运行：

```powershell
uv run --locked python experiments/corpus/prepare.py --decode
uv run --locked python experiments/corpus/prepare_scoring_reference.py
uv run --locked python -m unittest discover -s experiments/corpus -p 'test_*.py' -v
```

准备脚本默认只提取开发章节。冻结后需要提取验证或保留输入时，加 `--partition validation` 或 `--partition heldout`。视频、字幕、探测 JSON、FFmpeg 和输出根目录可通过参数指定；脚本对原字幕哈希、日语音轨、零原点和既有冻结内容进行核对。既有 manifest 不一致、剪裁范围被复用为另一范围、PCM 哈希变化均会报错，不能静默覆盖。所有输出位于被 Git 忽略的 `.local/`；`D:/movie/` 始终只读。

已在原生 Windows、uv 项目 Python 3.12.15 环境通过 4 项离线合成测试，覆盖 SDH 规则、不可覆写 manifest、样本精确剪裁/偏移与复用、SRT 源时间解析；全片解码和 5 个开发章剪裁实际完成。后续模型比较应使用[时间同步评估方法](subtitle-timing-benchmark.md)和[运行记录约定](stt-evaluation.md)，另行冻结正式筛选规则。
