# 参考译文 v3 复核：修正与置信度

日期：2026-10-10。状态：concluded（复核完成；冻结由 `python -m experiments.translation_v3 freeze-reference` 生成 `reference-v3/freeze.json`）。
范围：v2 参考集 `reference-v1` 的全部 144 窗、720 条评分 cue，包括筛选 screen-a／screen-b 各 48 窗、确认集 48 窗。这些参考作为 [v3 计划](../plans/hy-mt2-translation-flow-exploration-v3.md)中 `claude-opus-5-5-mqm-v1` 裁判的辅助参照。

## 方法

- 复核者：3 个 Claude Opus 5.5 子 agent，按作品分片：
  - 分片 1：W01、W02、W03、W06
  - 分片 2：W09、W11、M01
  - 分片 3：M02、M03、M04
- 输入：每窗完整的可见日文上下文；评分 cue 的日文、字幕组原译 `original_zh`，以及 v1 修订参考 `zh`（由 Sol/high 双轮复核）。
- 规则：只改有日文依据的明确语义问题，即误译、漏译、增译、指代错误、否定／数字／条件错误、跨 cue 归属错误。不按风格偏好改写，保留原文歧义。
- 每条 cue 给出：
  - 置信度：high／medium／low，判断依据是只看文本、不看音画时，能否确定参考正确；
  - `ambiguity_zh`：裁判应当容忍的其他合理理解。
- 隔离：复核 agent 不参与 v3 候选设计。确认集参考只进入评估侧文件，方法开发者（goal 主会话）不读取。

## 发现的系统性问题

1. **跨行重排**：字幕组常把一句跨多条 cue 的长句按中文语序重新分配到各行，个别条目内容与日文 cue 对不上。明确错位的 5 处已修正。其余写入 `ambiguity_zh`：逐条直译或合理跨行重排都不应重罚。
2. **补出省略成分**：参考常补出日文省略的主语、宾语，或按剧情具体化。这类条目标为 medium，并注明直译同样可接受。
3. **名称与短语有多种译法**：人名、音译、告别语、语气词有多种合理写法，已列为可接受的替代译法。
4. **依赖画面**：未完句、短叹词、说话人需要看画面才能确定的台词，标为 medium。

## 限制

- 只基于文本复核，没有核对音画；置信度为 low 的条目数为 0，不代表全部正确，只表示没有发现无法判断的条目。
- 复核者与 v3 裁判同属 Claude 模型家族。参考和裁判可能共享偏差，这一风险已在 v3 计划中记录。
- 逐条结果（含字幕文本）只保存在 `.local/translation-evaluation/hy30-flow-v3/reference-review/`，不进入 Git。
