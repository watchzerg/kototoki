## 接跑手册（每次启动或配额恢复后，从这里开始）

1. 运行 `uv run --locked --offline python -X utf8 -m experiments.translation_v4 status`。它只读文件，列出各 run 的生成与裁判进度、`judge-blocked.json`、GPU 锁、队列、参考冻结状态和建议的下一步。**以它的输出为准，不以本台账的文字状态为准。**
2. 只读核对 GPU：PowerShell `Get-Process | ? ProcessName -match 'llama|python'`、`nvidia-smi`，读 `.local/gpu.lock`。锁被存活 PID 持有时说明生成正在跑：不要再启动生成，不要杀进程。
3. 生成（GPU，不消耗 Claude 配额）：`queue add --recipe R --set dev`，然后**后台**运行 `run-queue`。已完成的 run 与场景会跳过，中断后重跑即可续上。
4. 裁判（消耗 Claude 配额）：`judge --run <RUN>`（CLI 执行面，profile `claude-opus-5-5-mqm-v1` 不变）。
   - 退出码 **75**：配额用完或未登录，详情见 `judge-blocked.json`。不要循环重试；先做不需要裁判的工作（生成、派生多候选、统计、写台账）；没有可做的就停下，恢复后从第 1 步开始。
5. 统计：`compare --candidate <配方> --set dev [--stage A|full]`；判定规则以冻结的 `decision-policy-v4.json` 为准（冻结前拒绝查看候选成绩）。
6. 每完成一个候选，在“执行记录”追加一条：假设 → 唯一变化 → 结果（Δ、SE、类别、critical、交付、墙钟）→ 判定 → 下一步。失败也记；未知值不填 0。

### 2026-10-11 R1：v3 数据的回溯方差分解（方向 1）

代码：`experiments/translation_v4/retro.py`（只读 v3 产物）。单位：每窗（5 条评分 cue）accuracy 惩罚均值；只用代表窗（筛选 72 窗）。

- 方差分量（每窗）：裁判重复 σ²_J ≈ **0.030**（C0 s08、s10 两次重评，144 对）；seed σ²_S ≈ **0.073**（20 个配方的窗口内跨 seed 方差均值 0.103 减去裁判部分）；配方×窗口真实效应异质性 σ²_τ 中位数 **0.126**（joint 0.066、b10-joint 0.085、b40 0.244）。
- 验证：bws 与 C0 几乎逐字相同（同 seed、只改空白 grammar），其逐窗 Δ 方差 0.0215 ≈ 2σ²_J/3 = 0.020，说明裁判噪声估计可信。
- 窗口内 5 条 cue 的配对 Δ 相关（ICC）只有 −0.01～0.09：效应异质性基本在 **cue 层面**，连续 cue 与分散 cue 提供的信息几乎相同。
- 作品间效应方差很小（b10-joint 作品均值方差 0.011，与纯窗口噪声相当）。
- **关键发现：v3 的不确定性被低估约 2.5 倍。** v3 按作品聚类 bootstrap（剧集 6 簇、电影 3 簇）给 b10-joint 的 SE 是 0.018；在作品内按窗口分层重抽，SE 为 **0.044**。用后者看：筛选 −0.093 与确认 −0.012 之差约 0.08，只相当于约 1.1 个联合标准差，再加上从约 20 个配方中挑最佳的赢家诅咒，就能解释，不需要“同作品新窗口方向翻转”这种异质性解释。
- 15 个筛选候选的 |Δ/SE| 均值为 0.83，而全为零效应时期望约 0.80：v3 的配方效应基本都在噪声内。
- 指标比较（screen-a 与 screen-b 的候选 Δ 相关 / |z| 均值）：accuracy 惩罚 0.30 / 0.83，major+ 率 0.11 / 0.68，任意 accuracy 错误率 0.10 / 1.10，封顶 5 的惩罚 0.25 / 0.78。没有明显更好的替代指标，主终点保持 accuracy 惩罚，错误率作次要指标。
- 设计含义（每条 cue 配对方差约 5×(σ²_τ + 2(σ²_S+σ²_J)/S)）：
  - 判定精度主要取决于**评分 cue 总数**；第二次重评只能把配对方差降约 13%，不划算。
  - 在 cue 供给不受限时，每场景 1 个 seed、把 3 个 seed 分到不同场景块，单位裁判成本的效率约是 3 seed 全覆盖的 1.7 倍。
  - 在 cue 供给受限时（电影），增加 seed 才划算。
  - 检出 3–6% 的效应（0.013–0.026）需要每臂约 2–8 万条评分 cue；电影在库中只剩约 2000 条新 cue，按 50:50 加权时总体 SE 的下限由电影决定。所以本轮**无法**可靠检出 3–6% 的效应，可达到的目标约为确认集 MDE 0.03–0.04（约 7–10%）。
