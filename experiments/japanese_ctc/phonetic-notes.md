## 映射证据的限制

`phonetic.py` 将每个读音块记录为半开坐标：`original_start/end` 与 `target_start/end`。
原生 `orig` 必须连续、完整地复现转换输入；省略、重排或改写原文会拒绝。
原文中的 `、,。` 以及首尾空白始终保留在最终完整文本中。

- 能证明一对一的假名形式变化可保留字符时间，例如 `シンジ → しんじ`。
- 一个原文字对应多个假名时，可使用全部假名的声学跨度，例如 `猫 → ねこ`。
- 多个原文字对应读音时，仅保存整个块的词级跨度，例如 `東京 → とうきょう`。
  `東` 和 `京` 保持无字符时间，不能等分或复制该词跨度制造字符精度。
- 任一必要假名 OOV、缺少 token 或时间非有限／倒序／重叠时，整个对应块保持无时间。
- 跨越两个原文映射块的 token 不猜测拆分；保留缺失证据。

词级 `words` 含明确原文 `char_start/end`，调用方应把这些真实范围提供给评测器。
仅统计原文 `chars` 的可测比例，会漏掉有效的多字词级跨度；反过来把词级跨度伪装成
每字时间也会高估边界精度。对齐成功统计需要注明这一粒度区别。

## 本地读音观察

以下为合成文本的本地实际输出，不是电影台词准确率评估：

| 合成输入 | pykakasi 2.3.0 输出 | 含义 |
| --- | --- | --- |
| `今日は東京へ行きます` | `こんにちはとうきょうへいきます` | `今日は` 被当作问候语，读音可能与上下文不一致。 |
| `一日` | `ついたち` | 不能保证语境需要的 `いちにち`。 |
| `生` | `なま` | 多读音字需要额外语境或明确的读音输入。 |
| `3人` | `3にん` | 数字保留，不能声称已完成数字读音归一化。 |
| `１２人` | `１２にん` | 全角数字同样保留；词表覆盖需实际检查。 |
| `シンジ` | `しんじ` | 可证明逐字对应。 |
| `ラーメン` | `らーめん` | 长音符保持，是否可对齐由 checkpoint 词表决定。 |
| `ｷｮｳ` | `きょう` | 原文半角假名坐标被保留。 |
| `ABC！` | `ABC！` | 英文与其余标点未被随意改写成假名。 |

这些读音可以进入模型原生路径的可行性验证，但不能把成功返回 CTC 时间等同于
读音正确。本轮若质量改善有限，读音歧义、保守词级映射与许可边界都会影响是否值得
纳入当前体系。需要另行标注真正声学边界才能证明字符或词级时间准确性。
