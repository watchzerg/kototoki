## 运行前冻结

本地清单 `.local/x0-flow/pilot-v1/study.json` 在任何新识别前创建，记录两片各 window-01、
各300秒、PCM／参考／源字幕 SHA256、源偏移和评价规则。这是沿用 W0 回归输入的开发筛查，
不是盲测，也不是全部电影声音场景的代表性保证。来源见[素材规范](../testing/fatestay-reference.md)。

| 独立身份 | 唯一上游策略变化 | 保留范围 |
| --- | --- | --- |
| `fixed30` | 当前基准：固定30秒 | 全部原音频 |
| `energy` | 上限前5秒内，100ms 能量窗口选择低能量切点，最长30秒 | 全部原音频，不重叠、不删静音 |
| `pyannote` | 直接复用 W0 的现有 Pyannote／min-cut／merge | 过滤块外音频，块内仍为连续原音频 |

三组固定 Qwen 1.7B、BF16、SDPA、日语、独立 greedy、batch1、max4096；
固定 `experiments/w0_demo/alignment.py` 的 MMS jpn、CUDA FP32、归一化及 TF32 作用域。
ASR 和 MMS 环境版本不同，以阶段进程连接同一源坐标契约；不复制 MMS 或 VAD 实现。
不同时修改 padding、解码、重叠去重、特征、批量或模型精度。

先运行离线坐标／完整性测试，再串行运行六条完整链。逐阶段记录加载、推理和进程墙钟；
保存全文、token、窗口、源码／模型／输入身份及设备证据在 Git 忽略的私有目录。

## 评价与停止规则

复用现有评分器及 round2 跨边界规则，比较完整文字的 CER／替换／删除／插入，重复诊断，
完整参考分母的内容和时间覆盖、严格半秒成功、严重偏移及共同可测集合；不裁掉难对齐文字。
插入字符不自动等于幻觉或重复，真实歌声保留不算 VAD 误报。
本轮无人工声学标注，SRT 时间差不称作发声边界误差；两窗不计算 bootstrap。

只有两片均显示可信收益且内容／覆盖无观测回归才考虑扩大；否则报告取舍并停止，
不根据结果调整切点、阈值或样本，不自动改默认配置。
VAD 辅助切点但保留全部音频、其他 VAD、padding、重叠窗口和批量吞吐均留作独立问题。

结论写入研究报告并更新索引；检查 README、AGENTS 和受影响文档的准确性。
