## 结论

不需要下载页面标注的全语言约 60.3 TB。音频、时长和字幕分目录提供，可以先花不到 1 MB 获取两个日语子集的全部时长，再按候选所在分片获取字幕，最后下载少数音频包。

准确率／时间评估优先 `ja000`，因为 `ja100` 是平台自动字幕；但 `ja000` 只表示上传者提供字幕，并不保证人工、同语音语言或逐字覆盖。本轮在长记录字幕中发现疑似译文、整场仅一条说明文字及道路／登山地点标记，因此不能直接把日语配置里的全部记录当成合格日语 ASR 样本。

## 核验方法与版本

固定 Hugging Face revision：`c9674490249665d658f527e2684848377108d82c`。

通过官方仓库 API 读取两个子集的 audio／duration／text 目录清单；下载全部 514 个 duration 文本，解析 `audio_id seconds`。合并出 32,899 条记录，再读取 `ja000` 的 29 个字幕 JSON，共检查其中 63 条至少一小时的候选，包含全部 26 条至少两小时的候选。选择另外五个分片的依据是其中至少一小时记录最多；此法只为试查，不代表随机抽样。

已核验两子集各自的记录数与唯一 ID 数一致、时长为有限正数，并独立重算原文件总时长，与汇总结果相符。duration 和所选 text 原文件合计 16,116,960 bytes；另有少量目录响应和一个格式检查用字幕副本。没有获取任何音频包，也没有执行第三方数据加载代码。

来源：[固定版本仓库](https://huggingface.co/datasets/espnet/yodas2/tree/c9674490249665d658f527e2684848377108d82c)、[官方 loader](https://huggingface.co/datasets/espnet/yodas2/blob/c9674490249665d658f527e2684848377108d82c/yodas2.py)。以下数值是本次从元数据计算的结果，不是官网人工筛选后的合格日语语音统计。

时间覆盖率在这里定义为字幕区间裁剪到录音范围后的并集长度／录音总长。它不是语音覆盖率，更不是文字正确率。字幕可能跨越停顿，极长单条提示也会制造高覆盖；要同时看条数、单条跨度、正文密度、重复、开头结尾缺口、语言及内容类型。正常音乐／静音也可能产生低覆盖，不应机械淘汰。

## 下载方式与 streaming 限制

官方非 streaming loader 会为整个所选配置准备所有 audio tar、字幕和时长文件。因此不要为了找样本直接加载整个 `ja000`。其 streaming 分支也按顺序读压缩包，每条 `audio_f.read()` 后才 yield；在流上追加 duration filter 仍会先经过不符合条件的音频，不能保证省流量。[已核查源码](https://huggingface.co/datasets/espnet/yodas2/blob/c9674490249665d658f527e2684848377108d82c/yodas2.py)

最明确可控的方式是：时长清单 → 少数字幕 JSON → 人工选出候选 → 只获取对应 tar.gz → 按 ID 提取所需成员。普通 tar.gz 不是可按任意成员直接随机读取的独立音频目录；顺序流式读取可能在找到目标后提前停止，但不能事先承诺只传输目标文件大小。此轮未验证包内真实文件及实际下载／解码。
