# 以时间同步为优先的字幕评估标准

## 1. 核心原则：不把断句不同当作识别错误

评价的是“说了什么、发生在什么时候、最终如何显示”，三者分开计分。

| 情况 | 文字识别 | 内容时间 | 字幕显示 |
| --- | --- | --- | --- |
| 参考一条，输出拆成两条，文字和底层词时间相同 | 不扣分 | 不扣分 | 检查显示是否连续、是否闪烁 |
| 参考两条，输出合成一条，文字和底层词时间相同 | 不扣分 | 不扣分 | 检查是否过长或跨越静音 |
| 文字正确，但整体晚 1 秒 | 正确 | 记录约 1 秒偏移 | 记录晚显示 |
| 漏掉前半句，后半句时间正确 | 记录删除 | 后半句可作局部诊断，整段不能算完整同步成功 | 记录内容缺失 |
| 只有一个长 segment，没有内部词/字时间 | 可正常算文字准确度 | 内部跨度记为时间分辨率不足 | 按实际显示评价，不能伪造词时间 |

例如参考为 `今日はいい天気ですね`，输出可以是一条，也可以是 `今日は` 与 `いい天気ですね` 两条；合并规范化文字后相同，CER 应相同。若其底层文字时间映射也相同，主要时间分数也必须相同。标点、换行、SRT 编号和 cue 数量不参与主文字指标。

这里不要求字幕逐字跟随声音显示。一个 cue 同时显示一句话是正常行为；不能给每个字都套上该 cue 的起止时间，再据此宣称词级对齐很差。

## 2. 原始参考、人工参考和数据划分

默认读取 Heaven’s Feel II、III 已分离的日语音频和同目录 SRT，原版内嵌日文字幕作为精确主参考。Heaven’s Feel I（双语字幕抽取）可信度较低，Black Panther（英文电影的日语配音与日语字幕）可信度最低，仅作补充参照；路径、SHA256 和只读保护以[素材文档](fatestay-reference.md)为准。无需重新提取视频音轨；必要的解码、下混、重采样与裁剪从已有音频开始，并记录源时间映射。

两片主参考分别报告，主汇总仅包含 II、III；补充片单独报告参考差异与局限，不参与主排名。原版字幕的精确参考地位不等于词级声学真值。旧单片 1,030 条原 cue 及其后续 scoring-v2 属于[历史冻结](2026-10-04-corpus-freeze.md)，不能作为当前两片语料的分母。新轮次另冻样本、参考身份和分集，已接触片段不能重新冒充独立保留集。

建立派生参考清单，保存原 cue ID、场景 ID、规范化文字、原始显示时间、口述/非口述标记和分集信息。人工修订写入派生标注，不改原字幕。声音描述、角色名标签、歌词、重叠说话和非逐字改写单独标注；不能看到某候选结果差再排除这些内容。

参考分两层：

- **原始 SRT 参考**：覆盖较广，适合发现显示偏移和整片异常，但编辑性延时和非逐字内容可能影响指标。
- **人工核对参考**：听辨文字和实际发声起止，注明边界不确定范围。它用于声学判断；不能由某个待测 aligner 自动生成再当真值。

先从独立选定的分层样本中核对至少 40 个片段，作为整体标注预算的一部分，检查媒体原点、参考可靠性和编辑性时间差。初始人工预算约 200 个片段：开发 60、验证 40、保留测试 100；困难样本可补充，但另列诊断表。无法可靠听辨的项目记录原因，不凭字幕时间猜测声学标签。

场景分集先于候选结果：目标约 200 个原始 cue 用于调参、150 个用于验证、其余保留，实际按场景边界和参考有效性确定。同场景、音频 overlap、上下文和相关参考不得跨集合，必要时保留隔离区。模型输入窗口不能用参考字幕边界规划。人工标注和匹配规则的开发也只能使用开发集；测试参考可由独立标注流程预先制作，但不得成为调参输入。

歌曲、重叠说话和静音分别报告。代表性抽样、刻意选择的困难案例不能直接混成无权重总体指标。已有历史失败案例只能用于诊断或回归，不宣称未见过的测试数据。

## 3. 文字准确性：按场景连续文字计算

每个预先固定的场景，把参考和完整候选输出分别按原有顺序拼成连续字符序列，再做 edit alignment。不按照候选分句切开评分，也不只取成功匹配到时间的文字。

冻结以下规范化约定：Unicode NFKC；去除约定的空白、换行和标点；移除参考中明确的非口述标签。保留原文、规范化文字及字符映射。汉字/假名、同音异字、数字写法不能全部自动等同；可另给固定规则下的表记容错辅助分数，不能替代主 CER。不得通过 LLM 改写语义后计算主分数。

定义：

`micro CER = Σ(S + D + I) / Σ参考字符数`

其中 S 为替换，D 为删除，I 为插入。分别报告 S/D/I、删除率、重复、专名和数字问题。使用全场景完整输出，所有未匹配插入、重复和漏字均计入。时序匹配失败不能让文字从 CER 中消失。

纯静音场景的单独 CER 为“未定义”，不能记为 0；其幻觉字符仍作为 I 加入整个有非零参考字符数的语料 micro CER 分子。同时单独报告静音幻觉字符数、事件数/分钟；连续幻觉段作为一个事件，并冻结事件合并规则。

参考本身存在删改而未经听辨的场景只能报告“相对 SRT 的文字差异”；人工核对集合另外报告较可信的识别 CER，不能把两者混为同一个精确真值指标。非口述标签在预先制定的参考规则中删除，候选输出中无法对应实际语音的文字仍是插入，不能按候选临时豁免。

长视频采用预先固定场景和单调全文文字映射分配计数，不能按候选时间戳先裁掉迟到文字。每个输出字符在整片统计中计一次；跨边界归属不明时记录为匹配问题，仍保留整片文字总分。重叠窗口重复只有被冻结的正常推理合并逻辑真正去重才不算插入。

## 4. 内容匹配和时间粒度

参考评估单元是预先固定的“文字跨度”，以原 cue ID 为来源，必要时在人工标注阶段拆成可听辨发声片段。它不是候选的句子、word 或 cue。跨度边界不能根据候选的好坏调整。

先按规范化文字序列、上下文和顺序确定对应关系，再读取时间。允许一对多、多对一，参考跨度只计一次。不按最近时间、相同 cue 序号或最小时间误差找配对；重复台词用前后文字消歧，仍不确定则人工盲审，不能挑最有利的一次。

保存“规范化字符 → 原文字 → 后端时间单元”的映射。不同后端的字符、词、nagisa 单元不能用数组下标直接对齐。使用已暴露的最早/最晚有效边界重建同内容跨度的时间；若内部粒度不足，则明确为粗时间或不可测，不能按字数比例分配时间，也不能拿参考边界补全。

部分词替换但身份明确的跨度可以测量边界；漏掉首尾词、只识别半句时应区分“已识别部分的局部时间”和“完整内容同步”。这避免把剩余半句时间正确误报为整句成功，也避免把漏字全部描述成 aligner 时间偏移。

匹配算法、重复台词策略和盲审规则在开发集冻结。盲审尽量隐藏路线身份及时间误差，仅凭参考、候选文字和必要音频确定内容身份。评测器不确定与实际模型失败是两种原因，必须分列。

## 5. 三张独立计分表

### A. 相同内容的时间位置

对固定参考文字跨度，用后端原生/独立对齐的起止边界计算误差，不使用 writer 的外层 cue 包络替代细粒度时间。

分别输出“相对原始 SRT 显示边界”和“相对人工发声边界”两张子表，不混合计算一个 P95。媒体/音轨原点错误应在前置检查中证明并统一修正；禁止为每条候选拟合最佳整体 offset 以改善成绩。

若原 SRT 的编辑性提前/滞留已系统性超过目标容差，先确定可比较范围和主要参考，再开始选型。原 SRT 仍是默认对照，人工声学结果用于解释是否真正错位，而不是强迫准确的 FA 模仿字幕滞留。

### B. 完整性与失败原因

固定总体 N，逐项统计：文字覆盖率、首尾完整的跨度覆盖率、具备所需时间粒度的覆盖率，以及缺失语音、对齐失败、回退/插值、非法时间、匹配歧义和参考不确定性。

删除、含糊配对、粒度不足不能在报告里消失。有效的粗 segment 可作为实际可用输出，但不证明词级对齐成功；API 已做修正的结果只能称为 API 输出，不能冒称未经处理的 raw logits。不可见的回退比例记为未知，不是 0。

### C. 最终字幕显示

分别评估原生 writer 与统一最小 writer，检查显示时长、闪烁、跨长静音合句、内容丢失、重叠/截断、过早消失和过晚出现。允许合理合句、拆句，不能以复现原 SRT cue 数量为目标。

原方案对每个合句直接套用参考 cue 起止门槛容易把编辑差异误判为 ASR 错位，本版取消这种硬性淘汰。显示问题仍可阻止“最终字幕可用”的结论，但不能直接否定上游识别/对齐；应先用固定 word 结果重放 writer，确定责任层。

## 6. 时间指标、覆盖率和不确定项

对参考和内容身份明确、起止完整且具备足够时间粒度的跨度 i：

- `ds_i = predicted_start_i - reference_start_i`，正值表示晚。
- `de_i = predicted_end_i - reference_end_i`，正值表示晚。
- `E_i = max(abs(ds_i), abs(de_i))`，要求两端都准确。

报告有效匹配集合的起点/终点有符号中位数、绝对误差 P50/P90/P95/P99、最大有限误差和 >0.5/2/5 秒的数量。分位数统一用 nearest-rank：排序后取一基索引 `ceil(p × n)`，每项附 n 和覆盖率。P95/P99 是误差分位数，不是 true-positive precision。

为防止只剩少数容易项时 P95 很好看，还必须提供全体分母上的联合成功率：

`success(t) = 起止完整、时间可测且 E < t 的参考跨度数 / N`

`N` 包含预选合格参考中的缺失和失败项；分子不能计入只有半句成功的条目。另提供字符覆盖率和局部边界统计，避免“一个漏词导致整段失败”掩盖真实原因。

无法判定的匹配记为 U。在盲审解决前，报告保守下界 `success_count / N` 和乐观上界 `(success_count + U) / N`；U 只包含可能满足该条件的未决项。未决项多到能改变排序或是否达标时，结论是证据不足，而不是自动宣判某引擎失败。已确认模型失败不进入 U。

可给出将内容不完整、时间无效或不可测项设为 `+infinity` 的全体联合分位数作为保守摘要；已知有效有限误差即使超过阈值也保留原数值。该摘要必须称为“完整性与时间的联合指标”，不能把无穷值解释为实际无限偏移。它不能替代条件时间分布和逐类失败率。

人工边界同时保存最佳点估计和不确定区间。描述性分位数使用冻结的点估计规则，另报告区间下误差的敏感性；不能为不同候选选择最有利的参考时刻。判定阈值时，只有整个可能误差区间都位于阈值内才算确定成功，全部位于阈值外才算确定未达到，其余计入未决项 U。标注不确定性过大时先复核参考，不通过调整候选时间抵消。

## 7. 初始目标与正式规则冻结

| 项目 | 第一轮处理 |
| --- | --- |
| P95(E) < 500 ms | 保留为时间目标，分别注明参考类别、样本数、完整性和不确定性 |
| P99(E) < 2 s | 保留为尾部目标；小样本只提供观察值，不宣称稳定达标 |
| >2 s、>5 s、最差案例 | 全量列出并归因；先前“>5 s 必须 0”不再未经校准地自动淘汰 |
| 覆盖率、CER、删除率、静音幻觉 | 联合报告；先前 99%、15%、2% 仅是旧提议，不作为已接受门槛 |
| 无效时间、丢文本、CPU 回退 | 属于结构/执行故障，必须显式报错或标记，不能静默修饰为成功 |

正式质量保护线在参考抽查和未调优开发基线之后、验证/保留测试之前确定，写入版本化 `evaluation-config`：目标参考、阈值、最低覆盖率、要求的联合 `success(t)`、准确性可容忍退化、未决项上限、标注区间处理和晋级方法。必须明确条件 P95/P99、联合成功率、覆盖率如何共同决定晋级，不能只靠成功子集的分位数。本轮决策规则已记录于[第一轮筛选规则](evaluation-config-v1.md)，其中保守联合时间目标和晋级方法已冻结，具体入围清单仍须在验证前锁定；缺少独立声学参考及产品质量容忍度的部分保持未验证，不能称产品验收标准已完成。

设定质量保护线必须说明可接受的用户影响、参考误差和样本证据；不能简单按最差候选倒推一个让所有路线都通过的门槛。若开发证据仍不足，只输出探索性对比并补充数据，不强行作通过/不通过判断。

初始选型顺序：本机 GPU/离线/稳定性 → 已确认的大偏移和缺失 → 时间尾部与完整性 → 文字质量 → 资源及部署成本。提供 Pareto 表；差异小于标注分辨率或置信区间无法区分时允许并列。原先固定 50/200 ms 的“平局线”不再视为通用定律。

测试阶段只应用冻结规则。不能看到某路线不通过再调门槛、改参考排除项或换文字规范化；变更后需新一轮身份及新的独立验证依据。

## 8. 样本量与统计边界

保留的数百条原 SRT 跨度适合描述该电影的字幕差异，但相邻对话相关，并非独立抽样。约 100 个人工核对保留片段的 P99 几乎由最差的少数项决定，不能作为全片或一般日语的 99 分位保证。

先报告观察到的误差、事件数和覆盖率；只有尾部结论会改变选型时，才扩大独立人工样本。若扩展是在看过失败案例后挑的，必须作为诊断集，不能冒充代表性测试。FateStay 单片也不能证明跨作品、语言或声音条件的泛化能力。

在场景数足够时，使用按场景成组的 paired bootstrap（初始 2,000 次，记录 seed）描述候选差值的不确定性，保留同场景相关性。场景太少或尾部很稀疏时不强行输出看似精确的区间。只有两个分位估计都有限才相减；否则报告非有限比例、阈值成功率和覆盖率差异，不计算 infinity-minus-infinity。

两候选的条件时间分布可能来自不同成功子集：除各自全表外，补充共同有效子集的成对比较，仍同时展示原始全体覆盖率。不能靠只取共同成功子集隐藏一条路线的更多失败。

重复运行用于检查速度与非确定性，不增加独立参考样本量，不把三次结果当作三倍 N，也不平均时间戳来消掉偶发大错。

## 9. 评测器自身的验证

真实推理前用小型合成例子验证以下行为；这些测试验证计分，不证明声学效果：

- 仅合并/拆分 cue，保持文字与底层时间不变：主 CER 与内容时间分数不变。
- 标点/换行变化不改变主 CER；漏词、重复、纯静音幻觉正确进入 D/I 和全体统计。
- 相同文本整体移动 1 秒：CER 不变、时间误差正确变化。
- 一对多、多对一、重复台词、边界缺词、粗时间和 text-only 结果处理正确。
- crop offset、重采样、padding 和去静音分段映射恢复正确；不按累积舍入制造漂移。
- 缺失和歧义仍留在分母，未决上下界及非有限分位数处理正确。
- 缓存命中、重算与参数变化可区分；writer 不删除无词时间但有文本的内容。

## 10. 证据、成本和结论

采用[通用运行记录](stt-evaluation.md#run-record)，补充文档/模型版本、分集和参考 revision、匹配算法、字符映射、时间来源、每类分母、未决项、冻结规则和校验结果。保存最差 20 例及全部 >2 秒/失败例的隐私安全 ID，完整音频和文字留在 Git 外。

同一源场景可以经过不同原生预处理，但各阶段 PCM 身份、延迟/时间映射、设备和耗时必须记录；组件归因时固定实际阶段输入。人工标注、盲审和匹配排错时间也是实验成本，应与模型运行成本一起报告。

最终分别说明“文字质量”“内容同步”“最终字幕体验”“本机运行可靠性”和证据范围。参考不足、匹配未决、没有模型资产或没有真实 GPU 执行，都不能写成通过。评测器实现与开发实验状态以执行记录为准；本轮冻结规则与未验证项见[第一轮筛选规则](evaluation-config-v1.md)。
