复制 v4 b10-joint 主 seed run 为 `b10-joint-ctl`，全集重判；dp6 在主 seed 20261011–13 各生成一个 run，全集裁判；配对比较（Q1 筛选）。

## 执行记录

- 2026-10-16 claimed。复制 v4 b10-joint 主 seed run 为 `b10-joint-ctl__s2026101{1,2,3}__dev`，`judge-control` 全集重判（93／84／93 包）；dp6 生成 3 个 run（284／246／281 s，0 失败），`subset`（全集窗口）＋`judge --candidate-only`。生成与裁判并行运行。

- 事后按候选包大小分组的逐条平均差（无区间，只作机制线索）：电影 1–5 句 +0.038（130 条）、6–9 句 +0.020（764）、10–12 句 +0.068（1088）；剧集 −0.097（124）、+0.021（1448）、−0.019（1843）。变差不集中在小包上。

## Answer

dp6 在 dev 主 seed（全集 5397 条，受影响 97.8%）上，**电影侧显著变差**，触发 §5 停止条件，dp6 停止，不做重复 seed。

- 非劣：剧集满足（上界 +0.023），电影不满足（上界 +0.095 > 0.05）；电影下界 +0.0003（p≤0 = 0.049），刚过显著线，按预先定的规则判为显著变差。
- wrong-referent 没有下降（+0.010），这是 Q1 关心的机制。包变小也没有带来可见的 mistranslation 回升（+0.009，区间跨 0），而且变差不集中在小包上。
- 译文逐字相同的 cue 在电影上也 +0.032：裁判看到的同窗邻条译文变了，对这些 cue 的判分也会跟着变。所以电影的 +0.047 有一部分来自"邻条变了"的判分连带，不全是这些 cue 自身变差。按 §2.1 的做法，这个噪声底只报告，不从主终点里扣除。
- 对照全集重判比 v4 原判低 −0.018［−0.031, −0.006］，与 v6 的 −0.012 同向：对照必须同时重判，再次确认。
- 成本：请求 648 对 554（+17%），墙钟 811 s 对 808 s（+0.4%，与裁判并行），输出 token +0.4%，输入 token +0.4%，可见 cue 均值 9.1 对 11.6，显存峰值 15.8 GiB 不变，交付失败 0／0。
