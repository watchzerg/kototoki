## Answer

**Q1 否定：提示级放开对 Hy-MT2 30B 在 ID JSON 约束下无效。** 两种措辞、两种挑包准则、54＋16 个多 cue 组，重排率主阈值 0.2 下为 0–6.2%，全部落在严格对严格的噪声底内；人工阅读没有一例"按中文语序把内容挪到相邻行"。更强的两步式措辞不带来重排，却引入邻文泄漏与无中生有，不采纳。`joint-understanding-v2` 与 `grp1` 保持票据 01 的版本与 hash，不再调整。

按研究文档 §5 停止条件（"Q1 重排率接近零且小样票据调整一次措辞后仍如此"）本轮结题，03–06 不执行；是否转备选路线（组级输出再程序切回）交 §8。

一个顺带观察：严格逐 ID 模式下模型已经把每行译成自足的中文（把日文末行的谓语在前行里补说，或在后行里重述主语），所以"同一句话被拆开导致中文语序别扭"在 dev 小样里并不常见；语序自由的收益上限可能比立项时估计的更小。这是 20 个包的观感，不是统计。

## 留给后续

- 若转备选路线，需要新的 grammar（每组一个字符串）与切回程序，是新一轮，不复用本票的小样驱动以外的东西。
- `sample.py` 的 `--criterion split` 比"覆盖最多"更能挑出真正拆开的句子，后续小样沿用。
