# W0／X0 四种 VAD 对照实验

状态：十组合执行与分析完成；119 项完成、1 项生成上限失败，失败保留计分  
最后更新：2026-10-05  
范围：原生 Windows／RTX 5080；两条原基线加四种 VAD，共十种组合。

2026-10-05 后续采用：用户在整片比较后明确采用 W0／X0 新 Pyannote＋MMS 基线，见[ADR-0003](../adr/0003-new-pyannote-baselines.md)。本计划为已完成的十二窗研究，旧 PyanNet W0／无 VAD fixed30 X0 是冻结对照身份；“默认不变”仅描述当时执行边界，不替代后续采用决定。canonical demo 的执行默认仍待迁移。

## 冻结口径

使用[标准基线入口](../guides/baseline-testing.md)，保留 W0 的旧 PyanNet／原切分合并和 X0 的无 VAD fixed30。
四种新增候选为当前 Pyannote segmentation 模型、Silero、FunASR FSMN-VAD、FireRedVAD。
框架版本与权重 revision 分别核验；FireRed 没有正式稳定发布，最新公开包仍标 Beta，作为用户指定的探索候选报告。
官方核验与精确版本见[版本记录](../research/2026-10-05-vad-stable-versions.md)。

同一冻结语料为 `.local/round2/plan.json` 的 II／III 各六窗，共 3600 秒、590 条参考、6544 个规范化字符。
这些窗口已经反复用于研究，不是盲测。输入与参考、原始音频／字幕在运行前后按冻结 SHA256 核对。
不改写原素材、既有输出、既有环境或历史分数。

新增候选采用官方检测默认参数并记录差异，再用共同的原时间跨度合并策略形成最多 30 秒窗口；
保留窗口内静音，不拼接不连续波形，不以参考字幕调整阈值。长语音的强制切分和官方 padding 明确记录。
比较对象是完整 VAD 配方，不能把后处理差异全部归因于神经网络。
W0 保持原 ASR 特征／解码，X0 保持 Qwen 原生特征／独立解码，两者保持同一 MMS GPU 配方。

每个候选每窗新执行 VAD 一次，其同一窗口清单提供给 W0／X0，两条分别重新执行 ASR／MMS。
导入 VAD 清单明确标记为外部预计算；VAD 进程成本和识别／对齐进程成本分别计量，相加仅称重构串行成本。
原 W0 使用完整原入口新推理，原 X0 使用完整 fixed30 入口；不把历史缓存成绩当新基线。

## 评价与限制

完整记账十种配置 × 十二窗；缺失、失败、生成触顶与局部对齐失败均保留。
沿用现有文字规范化与时间评测器，报告 CER／S／D／I、全参考分母半秒／两秒成功、覆盖、严重偏移、text_only、分片与运行成本。
分别列两片与汇总，使用既有跨边界不确定性规则；按完整分母时间成功解释改善，同时保留内容损失护栏。
本轮不进行结果驱动调参，也不自动改选默认基线。

字幕显示边界不是 VAD 声学真值；本轮不宣称得到 VAD F1 或声学召回率。
对白保留优先，保留歌声不算 VAD 假阳性。字幕未收录的歌词等可能影响文字插入指标，不能直接称作幻觉。
若需区分对白与歌词，必须另有可靠声学标签，不能凭模型输出自行判定。

## 执行步骤

1. 核验官方稳定版本、许可、API，隔离准备模型与环境。
2. 给 W0／X0 增加可审计的外部分段输入，保留默认路径；验证源坐标与失败记账。
3. 冻结源码和配方，先完成短窗 smoke，再串行执行十二窗矩阵。
4. 独立核验结果和源素材身份，汇总十组合，报告取舍、失败及未验证范围。
