# 轮次记录模板

新研究轮次复制下面的骨架到 `docs/research/<YYYY-MM>-<slug>.md`，并在 [INDEX.md](INDEX.md) 的轮次登记加一行。规则见 [ADR-0031](../adr/0031-research-layout-and-lightweight-records.md)（R2、R3）。`## ` 二级标题是必填项；带"（可选）"的两节可以省略。正文约 150 行以内。

不写进记录：文件或样本的哈希（git commit SHA 除外）、本机绝对路径、逐窗或逐条明细与大段日志、字幕或转写原文（短例外）、执行台账与接跑步骤。

```markdown
# <轮次名>：<一句话主题>

## 状态
active／concluded／stopped，一句话说明（结题或中止的原因）。

## 时间
立项与结题日期（YYYY-MM-DD）。

## 问题
这一轮要回答的一个策略问题。

## 策略
试了哪些方案，各一句；对照是谁（翻译默认对照 Q3）。

## 环境与版本
模型名与量化（repo＋短 revision 或版本号）、推理引擎及版本、关键依赖、GPU。

## 测试
数据集的类型、规模与来源类别（不写文件名与哈希）；指标与判据；裁判身份。

## 结果
少量关键数字，表格不超过约 10 行。

## 结论与去向
采纳／放弃／停止；对应 ADR 或产品变更的链接。

## 教训（可选）
下一轮应当带走的先验。

## 原始材料（可选）
归档 tag 路径，如 `archive/2026-11-18-pre-research-restructure:docs/research/<文件>`。
```

## 验收记录模板

产品验收记录放 `docs/research/acceptance/<主题>-<YYYY-MM-DD>.md`，一次一篇，必填标题：

```markdown
# <日期> <验收对象>

## 时间
## 对象
验收的产品改动、配方或 ADR。
## 环境与版本
## 测试
测了什么素材（类型与规模）、什么入口、什么判据。
## 结果
## 结论
```
