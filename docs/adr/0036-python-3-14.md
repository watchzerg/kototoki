# ADR-0036：Python 锚点由 3.13 改为 3.14

状态：已接受，2026-11-20（用户裁定），已实现。
替代关系：
- 取代 [ADR-0007](0007-bilingual-subtitle-pipeline-architecture.md)「环境」中的"Python 3.13"，以及选版规则里"Python 3.13 是锚点"中的版本号；
- 取代 [ADR-0034](0034-ubuntu-only-platform.md)「工具链分层」第 2 点中的 `.python-version`（`3.13`）。

范围：根环境（即产品环境）的 Python 解释器版本。

不改：CUDA 12 锚点、直接依赖版本、配方身份。

## 决定

1. `.python-version` 写 `3.14`，补丁版本由 uv 决定；`pyproject.toml` 要求 `>=3.14,<3.15`。
2. 选版规则的锚点改为 CUDA 12 与 Python 3.14，其余规则不变。
3. 直接依赖版本不变（torch／torchaudio 2.11.0+cu128、torchcodec 0.17.0+cpu、ctranslate2 4.8.3、faster-whisper 1.2.1、transformers 5.20.1、pyannote.audio 4.0.7），`uv.lock` 只换成 cp314 的 wheel；传递依赖版本也与 3.13 时的 lock 一致。

## 身份

配方 id 与 `recipe_hash` 都不含解释器版本，本决定不改任何配方身份。smoke 结果的 `python` 字段记录实际解释器版本。

## 依据

- 2026-10-14 只选 3.13，是因为 3.15 缺 CTranslate2／torchaudio／torchcodec 的 wheel，3.14 的边角依赖没核实。
- 2026-11-20 核实：torch、torchaudio 2.11.0+cu128，torchcodec 0.17.0，ctranslate2 4.8.3 都有 cp314 的 Linux x86_64 wheel；`uv lock` 在 3.14 下解析出 129 个包，版本与 3.13 时的 lock 完全一致。
- 同日在 CPython 3.14.10 上验证：`just gate-full` 通过（core 784 项、full 21 项）；`just verify-assets` 通过。
- `just smoke`（2026-11-20，CPython 3.14.10）三项全部 PASS：`ct2_after_torch` 5.1 s、`translate_product` 248.4 s、`names_product` 70.3 s。

## 未验证与已知限制

- 用真实视频跑小批量 `just subtitles`（VAD、ASR、对齐的真实路径）没有在 3.14 上做。
- 3.15 仍不可用：torchaudio 2.11.0+cu128 与 torchcodec 0.17.0 没有 cp315 wheel。
